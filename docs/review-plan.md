## 1. Объект ревью
Модуль `src/discount.py`, функция `calculate_cart_total`
(расчёт итоговой стоимости корзины с учётом промокодов
и уровня лояльности). Версия: ветка `develop`.

## 2. Цели ревью
- Точность расчётов (порядок применения скидок, округление).
- Защита от фрода (многократное применение промокода,
  отрицательные суммы, подмена уровня лояльности).
- Корректность применения скидок и ограничения
  максимальной скидки (не более 30%).

## 3. Измеримые критерии
- Отсутствие магических чисел (все пороги и коэффициенты
  вынесены в константы).
- Валидация входных данных (cart_sum > 0, допустимый tier,
  promos — список).
- Покрытие тестами > 80%.
- flake8 проходит без замечаний.
- Критические замечания устранены до слияния.

## 5. Чек-лист ревью
- [ ] Расчёт соответствует требованиям ТЗ
- [ ] Граничные значения обработаны (15000, 0)
- [ ] Нет магических чисел
- [ ] Входные данные валидируются
- [ ] Деньги не считаются во float (используется Decimal)
- [ ] Есть unit-тесты, покрытие > 80%

## 6. Сроки
Подготовка: 1 день. Ревью: до 2 дней. Доработка: 1 день.

1. Автор и рецензент обсуждают в комментариях PR (до 1 дня).
2. Если согласия нет, решение принимает Tech Lead.
3. Спор по архитектуре или рискам выносится на обсуждение
   всей команды. Решение фиксируется в PR.
